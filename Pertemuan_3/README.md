# Aplikasi Manajemen Buku Pribadi -MyBookSelf
Aplikasi Manajemen Buku Pribadi yang memungkinkan pengguna untuk menambahkan buku yang dimiliki,sedang dibaca, dan ingin dibeli , serta menampilkan statistik 
dari masing masing kategori tersebut.

## Cara Menjalankan Web
- Download & Install React  + Vite terelebih dahulu
- Clone Reporsitory ini atau download reporsitory.
- Masuk Ke Directory dimana repo ini berada
- Lalu buka terminal dan jalankan `npm run dev`

Pada fitur tambah buku baru , disini pengguna artinya memasukkan buku baru yang dimana parameternya berupa judul buku ,
