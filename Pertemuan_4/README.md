# Program Pengelolaan Data Nilai Mahasiswa

## Data Mahasiswa
Pada program ini sudah di deklarasikan 5 dictionary data mahasiswa yang bersifat statis atau sudah di inisialisasikan.
dimana setiap data memiiki attribute :
- nama
- nim
- nilai_uts
- nilai_uas
- nilai_tugas

## Fungsi
Program ini memiliki memiliki  8 fungsi dimana diantaranya :
- hitung_nilai_akhir (Berfungsi untuk menghitung nilai akhir berdasarkan parameter 30% UTS +40 % UAS +30 % Tugas)
- grade_nilai (Berfungsi untuk mengkonversi nilai akhir yang berupa numerik menjadi grade nilai yang berupa char)
- input_data_mahasiswa (Berfungsi untuk menginput data mahasiswa baru dengan validasi)
- filter_grade_mahasiswa (Berfungsi sebagai pencarian mahasiswa melalui equal string , dimana ketika kita ingin mencari grade tertentu , dan akan menampilkan data - data yang sesuai dengan grade yang di cari)
- rata_ratakelas (Berfungsi untuk menghitung rata - rata nilai akhir kelas)
- min_max (Berfungsi untuk mencari nilai tertinggi dan terendah dan menampilkan nama mahasiswanya)
- tampilkan_data_mahasiswa (Berfungsi untuk menampilkan atau output dari data - data mahasiswanya)
- main (Sebagai tempat pemanggilan fungsi fungsi yang sudah di sajikan dimana main ini lah yang akan di run nantinya)
